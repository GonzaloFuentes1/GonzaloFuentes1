## Proyectos destacados

**[LatamGPT](https://www.latamgpt.org/en)**
LLMs entrenados desde cero para América Latina. Modelos disponibles en [HuggingFace → latam-gpt](https://huggingface.co/latam-gpt).

**[DevorAI](https://devorai.up.railway.app/)**
Calculadora de recetas con IA orientada a vendedores de comida callejera en Chile. Optimización de costos e ingredientes.

**[Dreamer4](https://github.com/GonzaloFuentes1/dreamer4)**
Implementación propia de Dreamer v4 con mecanismo de atención asimétrica para world models.

**Trueque Benchmark**
Benchmark cultural de LLMs para Latinoamérica: 500 preguntas distribuidas en 20 países. Evalúa conocimiento regional en modelos de lenguaje.

**[constitutional-ai-data-pipeline](https://github.com/GonzaloFuentes1/constitutional-ai-data-pipeline)**
Pipeline de datos para Constitutional AI.

**[toxicity-classifier](https://github.com/GonzaloFuentes1/toxicity-classifier)**
Clasificador de toxicidad en texto.
